# Coffee Code Studio — Design System

> Updated: 2026-09-17 | Version: 2.0 (Portfolio)

## Purpose

Portfolio site for Rami — AI-Leveraged Product Engineer.

Goal: Attract employers in Gothenburg. Show real projects.

## Color Palette

| Token | HSL | Usage |
|---|---|---|
| --background | 235 45% 8% | Midnight blue — page background |
| --foreground | 45 20% 95% | Warm off-white — all text |
| --primary | 43 96% 56% | Amber/Gold — accent, CTA |
| --secondary | 187 100% 42% | Electric Blue — highlights |
| --muted | 235 25% 18% | Muted surface — cards |
| --accent | 122 39% 49% | Terminal Green — code details |

## Typography

| Role | Font | Class |
|---|---|---|
| Headings | Lexend | font-serif |
| Body | Lexend | font-sans |
| Code/tech | monospace | font-mono |

## Section Order (new portfolio)

1. Hero — Rami + stack + "Gothenburg, Sweden" + CTA
2. Projects — 2–3 case studies (PSAM format)
3. AI Methodology — How AI is used and verified
4. Tech Stack — Categorized matrix, no percentage bars
5. About — Short, honest, Swedish culture fit
6. Contact — Copy Email + GitHub + LinkedIn + CV

## Design Rules

- Minimal always wins over feature-rich
- Animations MAX 180ms
- No custom cursor
- No skill percentage bars
- Load time under 1.5 seconds
- Mobile-first responsive
